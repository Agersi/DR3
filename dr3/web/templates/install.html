Installing the local game server

DR3 runs a small local server on your PC that connects DiRT Rally 2.0 to this site. One-time setup takes about two minutes.

  1. Download the DR3 client: DR3-windows.zip. Extract it anywhere — keep the DR3 folder intact.
  2. Run DR3\DR3.exe — the server starts automatically. Easy Setup (on by default) asks for admin rights once and configures everything: the hosts redirect + a self-signed certificate for the game's online domains.
  3. Register on this site and verify your email.
  4. Generate a game token on your dashboard.
  5. Paste the token into the DR3 app and press Save, then press STOP and START again so the running server picks it up. Launch DiRT Rally 2.0 — club championships and results sync to this site, while official game content stays on the normal game servers.

To uninstall later: open DR3, go to the Logs tab and click Uninstall DR3 at the bottom — it removes the program folder and your settings. Press STOP first if the server is running.

Using SimHub or another Telemetry app

DR3 reads the game's live telemetry over UDP to compute real per-segment stage splits (used on the website and for time trial ghosts). It picks the port automatically: if your game config declares an enabled <custom_udp> stream, DR3 listens there (typically 127.0.0.1:20999); otherwise it listens on the game's own standard telemetry port (20777). No setup is needed if you don't use any other telemetry app.

If you run SimHub (or a similar tool) alongside DR3, keep that app on the game's standard port (20777) and forward its UDP telemetry output to the custom port DR3 listens on — for example in SimHub's settings, enable the UDP broadcast/forward option and target 127.0.0.1, port 20999. Both tools then receive data.

If the port is already taken or no data arrives, DR3 logs a clear message and splits simply fall back to an even profile — stage times and time trials still record normally. You can also pin a specific port with "telemetry_port" in the DR3 config.json.

Auto-launching DR3 and the game

DR3 starts its server automatically when you open it — the Start automatically when DR3 opens option in the Main tab is on by default, so simply opening DR3 gets everything ready before a session. Untick it if you prefer to press START yourself.

To start DR3 and DiRT Rally 2.0 with one click from Steam, make a small launcher file: create a new text file, paste in the lines below (adjust the DR3 path to your own install folder), and save it as e.g. DR3.bat on your Desktop or anywhere else permanent — not inside the DR3 folder itself, since updates replace its contents:

@echo off
 start "" "C:\DR3\DR3.exe"
 timeout /t 5 /nobreak >nul
 %*

Then in Steam: right-click DiRT Rally 2.0 → Properties → Launch Options, and enter (adjust the .bat name/path if yours differs):

"%USERPROFILE%\Desktop\DR3.bat" %command%

Now just press Play on DiRT Rally 2.0 as usual: Steam runs the launcher, which opens DR3, waits a few seconds, and then starts the game itself — so your playtime, overlay and everything else keep working normally.

Known limitations

  • Rallycross Tires screen: If using Rally cars on rallycross circuits the game shows a tire selection screen. Clicking this tire button WILL crash the game — this is a DiRT Rally 2.0 bug that can not be fixed by this mod. If you do happen to click the tires button, don't worry, you can simply restart the game and rejoin the club where you left off.
  • Terminal damage summary: If your car is destroyed mid-rally and you press Continue, the in-game event summary briefly shows every remaining stage of that rally marked as DNF. This is a DiRT Rally 2.0 display quirk that can not be fixed by this mod — only the stages up to the next service area are actually recorded as DNF on the website, and re-entering the club resumes at the correct stage. Nothing is lost; just continue back to the club screen.

Manual setup (Easy Setup off)

If you switch off Easy Setup Mode in the app, do these steps yourself instead. Everything below lives inside the extracted DR3 folder.

  1. Redirect the game's online domains to your PC. Run as administrator: 
    powershell -ExecutionPolicy Bypass -File scripts\setup_windows_redirect.ps1
    This adds a marked block to C:\Windows\System32\drivers\etc\hosts pointing the game's EgoNet domains at 127.0.0.1.
  2. Generate and trust a local TLS certificate: 
    python scripts\generate_dev_cert.py --cert runtime\certs\dr2server-cert.pem --key runtime\certs\dr2server-key.pem
powershell -ExecutionPolicy Bypass -File scripts\install_dev_cert.ps1
  3. Run the server headless: 
    python -m dr2server.httpd --data-dir data --ssl-cert runtime\certs\dr2server-cert.pem --ssl-key runtime\certs\dr2server-key.pem --api-url https://byagersi.com/rally --api-token df_...

To undo the redirect later: powershell -ExecutionPolicy Bypass -File scripts\remove_windows_redirect.ps1
