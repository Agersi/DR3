# DR3 client update log

What changed in each version of the DR3 Windows client, newest first.

**v0.1.58**
- Your best stage times are now tracked across club events, official dailies and time trials.

**v0.1.57**
- Club stage runs now record per-segment split times, so your best runs can be broken down section by section.

**v0.1.56**
- Fixed official stage times being recorded as Time Trial personal bests.

**v0.1.55**
- Your profile page now shows your driving stats — favorite car and location, most driven car and location, stages completed, distance, and input device — and you can pick on the account page which of those to show.

## 0.1.54
The window is a little taller so the update notice never forces scrolling, Uninstall DR3 moved to the bottom of the Logs tab, and closing while the server is running now offers Stop and Close.

## 0.1.53
After an automatic update installs when you close DR3, the install folder now opens so you can restart the app right away.

## 0.1.52
The server now starts automatically when you open DR3 — you can switch this off with the new option in the Main tab.

## 0.1.51
Fixed a bug where the automatic update was not installed when closing DR3.

## 0.1.50
When Verbose logging is on, closing DR3 now saves that session's debug log to a logs folder so it can be shared when reporting an issue.

## 0.1.49
DR3 now updates itself automatically — new versions download in the background and install when you close the app.

## 0.1.48
The main window now shows a small telemetry status line while the server is running, so you can see at a glance whether stage splits are being recorded.

## 0.1.47
Fixed an issue where split times were missing after finishing a club rally stage.

## 0.1.46
Fixed an issue where finishing a club stage could wrongly create or overwrite your time trial record.

## 0.1.45
Time trial results are now also recorded on the website, as personal bests per car and track.

## 0.1.44
Fixed a conflict with SimHub over a shared network port so both can run at the same time.

## 0.1.43
Stage results now include per-segment split times, and your total distance and stages driven are tracked on the website.

## 0.1.42
Test build for a championship layout experiment — no changes to normal play.

## 0.1.41
Added an experimental option to run a whole multi-leg championship as one event (off by default).

## 0.1.40
Fixed resuming after a wreck or retirement on longer legs so you continue from the correct stage.

## 0.1.39
Fixed missing car, class and flag on the leaderboard after retiring before a stage had started.

## 0.1.38
Fixed a game crash when starting the next rally after a wrecked stage.

## 0.1.37
Fixed retiring on the final stage of a rallycross round being recorded incorrectly.

## 0.1.36
Fixed a game crash when finishing a rallycross heat.

## 0.1.35
Wrecking a stage now correctly skips to the next service area, or straight to the next rally if there is no service left.

## 0.1.34
Wrecking your car now automatically advances you to the next service area, with skipped stages marked as not finished.

## 0.1.33
Fixed a game crash when continuing after wrecking your car mid-rally.

## 0.1.32
Fixed the wrong car class being shown in-game for Rally GT clubs.

## 0.1.31
Not-finished stages now show your car, class and flag on the leaderboard instead of a blank row.

## 0.1.30
Wrecking your car no longer records the stage as completed with a full time limit.

## 0.1.29
Driver flags now appear on in-game leaderboards, multi-location rallies show your total championship time, and the app tells you when a new version is available.

## 0.1.28
Added an in-app uninstall option.

## 0.1.27
Internal housekeeping — no changes to how the app works.

## 0.1.26
Fixed a startup error when pressing Start.

## 0.1.25
Improved the "Verbose logging" option and cleaned up unused settings automatically.

## 0.1.24
Improved the app window layout and removed the built-in overlay windows.

## 0.1.23
Renamed the "Streaming" tab to "Overlay" and fixed scrolling over its sections.

## 0.1.22
Fixed clipped text in the Overlay tab; scrollbars now only appear when needed.

## 0.1.21
Fixed the Streaming tab so all of its options are reachable.

## 0.1.20
Final test of per-car event restrictions — confirmed not possible, feature rolled back; no changes to normal play.

## 0.1.19
Further testing of per-car event restrictions — still crashed in the test clubs using them.

## 0.1.18
Experimental per-car event restrictions — crashed the game in the test clubs using them.

## 0.1.17
Added streaming overlays: text files for OBS/SimHub, a web overlay page, and a transparent in-game window.

## 0.1.16
Finished club events now show their results correctly in the Event Progress tab instead of a blank screen.

## 0.1.15
Fixed tyres carrying over incorrectly from rallycross to rally stages, and finished club event legs can no longer be restarted.

## 0.1.14
Fixed club leaderboards occasionally showing another club's results.

## 0.1.13
In-game club leaderboards now show your club's own results instead of official event data.

## 0.1.12
Rallycross cars can now be used in clubs, and your chosen car carries over between rallies in multi-location championships.

## 0.1.11
Added a per-event lap option for rallycross rounds.

## 0.1.10
Fixed wrong times shown on in-game leaderboards for later rounds of a championship.

## 0.1.9 and earlier
Initial development builds: connecting DiRT Rally 2.0 to the DR3 website, club browsing and stage submission, and the two championship types (Multi-Location Rally and Rally Season).
